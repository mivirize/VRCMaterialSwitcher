## 商品説明（本文）

```
衣装のマテリアルが入ったフォルダを指定するだけで、色違いをゲーム内の
Expression Menu から切り替えられる形に組み上げる Unity エディタ拡張です。

アニメーションや FX レイヤーを触る必要はありません。
アバター本体も改変しません。


■ 動作環境

・Unity 2022.3.x（2022.3.22f1 で動作確認）
・VRChat SDK - Avatars 3.x（3.10.4 で動作確認）
・Modular Avatar 1.9 以降（1.17.1 で動作確認）※必須です

Modular Avatar は VCC（VRChat Creator Companion）から導入してください。
VRChat SDK は同梱していません。


■ アバターへの影響

本製品はエディタ拡張です。アバターのパフォーマンスランクを直接下げる
ものではありません。

・パラメータ消費: 1 グループにつき Int 1 個（同期時 8 bit）
  VRChat の同期パラメータ上限は 256 bit です。
  現在の消費量はツール内に表示されます。

・容量: 切り替え先のマテリアルとテクスチャの分だけ増えます。
  ツール内に容量の試算と、解像度をまとめて下げる機能があります。

PC / Quest どちらのアバターでも使用できます。


■ できること

・衣装フォルダをスキャンして色違いを自動でグループ分け
  フォルダ名・ファイル名・UV トークンから「パーツ」と「色」を推測します

・どのメッシュのどのマテリアルスロットに適用するかを自動で推定
  バリエーションがアバターに割り当てられていない衣装でも、テクスチャの
  共有や命名を手がかりに適用先を特定します。決め手がない場合は候補を
  根拠つきで提示するので、選ぶだけで設定できます

・非破壊セットアップ
  Modular Avatar のコンポーネントを生成するだけです。FX レイヤーや
  アバター本体には触れません。生成物を削除すれば完全に元に戻ります

・手動編集
  グループの作成・分割、バリエーションの追加・削除、適用先の手動指定が
  すべて画面上でできます

・テクスチャ容量の試算と一括縮小

・便利機能
  Streaming Mip Maps の一括修正（アップロード時のエラー対策）


■ 使い方

1. アバターと衣装をシーンに配置する
2. メニューバーの [MIVI Works] > [VRC Material Switcher] > [ウィンドウを開く]
3. 「アバター」欄にアバターを設定
4. 「衣装フォルダ」に色違いマテリアルの入ったフォルダを設定してスキャン
5. 検出結果を確認（不要な色を外す / 初期色を選ぶ）
6. 「セットアップ実行」
7. アバターをアップロード

スクリーンショット付きの詳しいマニュアルを同梱しています。


■ 注意事項

・自動での色の見分けは「候補の提示」です。結果は必ず画面で確認して
  ください。意図と違う場合は手動で修正できます。

・アバター内にオブジェクト名が重複している場合、適用先を一意に決められ
  ないためセットアップを中断します。名前を変更してください。

・オブジェクト名に「/」を含めることはできません。

・Modular Avatar / VRChat SDK の更新により動作しなくなる可能性が
  あります。

・本ツールは Modular Avatar、VRChat のいずれとも公式な関係はありません。


■ AI 生成コンテンツについて

本製品にはスクリプトコード・ドキュメントを含め、AI により生成された
コンテンツが含まれます。


■ 利用規約

・本ツールで作成した成果物（アバター・衣装等）は、無償・有償を問わず
  自由に配布・販売できます。クレジット表記も不要です。
・本パッケージそのものの再配布・転載・販売はご遠慮ください。

詳細は同梱の LICENSE.txt をご覧ください。
ソースコードは GitHub でも公開しています（MIT ライセンス）。
https://github.com/mivirize/VRCMaterialSwitcher


■ 更新履歴

v1.2.3 - 表示崩れの修正、メニューを MIVI Works 配下へ、マニュアル同梱
v1.2.2 - メニュー整理

詳細は同梱の CHANGELOG.txt をご覧ください。
```
