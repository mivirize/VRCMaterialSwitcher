========================================================================
 VRC Material Switcher  v1.2.3
 衣装のカラーバリエーションを Expression Menu から切り替えるツール
 MIVI Works
========================================================================

【重要】本ツールの動作には Modular Avatar が必要です。
       VCC (VRChat Creator Companion) から導入してください。
       https://modular-avatar.nadena.dev/


------------------------------------------------------------------------
 1. これは何か
------------------------------------------------------------------------

衣装のマテリアルが入ったフォルダを指定してスキャンすると、色違いの
マテリアルを自動でグループ分けし、ゲーム内の Expression Menu から
切り替えられる形に組み上げます。

アニメーションや FX レイヤーを触る必要はありません。
アバター本体も改変しません（生成物を削除すれば元に戻ります）。


------------------------------------------------------------------------
 2. 動作環境
------------------------------------------------------------------------

  Unity                2022.3.x（2022.3.22f1 で動作確認）
  VRChat SDK - Avatars 3.x（3.10.4 で動作確認）
  Modular Avatar       1.9 以降（1.17.1 で動作確認）  ※必須

  ・VRChat SDK は同梱していません。VCC から導入してください。
  ・PC / Quest どちらのアバターでも使えます。
    （本ツールはエディタ拡張のため、アバターのパフォーマンスランクには
      影響しません。切り替え先マテリアルの分だけ容量が増える点にのみ
      ご注意ください。ツール内に容量の試算表示があります）


------------------------------------------------------------------------
 3. インストール
------------------------------------------------------------------------

  1) Modular Avatar を VCC から導入する
  2) MIVIWorks_VRCMaterialSwitcher_v1.2.3.unitypackage を
     Unity プロジェクトにドラッグ＆ドロップしてインポート
  3) メニューバーに [MIVI Works] が追加されます

  ▼ 旧バージョンから更新する場合
     先に Assets/Editor/VRCMaterialSwitcher フォルダを削除してから
     インポートしてください。ファイル構成が変わっています。
     設定（ProjectSettings/VRCMaterialSwitcherSettings.json）は
     そのまま引き継がれます。


------------------------------------------------------------------------
 4. 使い方（最短手順）
------------------------------------------------------------------------

  1) アバターと衣装をシーンに配置する
  2) [MIVI Works] > [VRC Material Switcher] > [ウィンドウを開く]
  3) 「アバター」欄にシーン上のアバターを設定
  4) 「衣装フォルダ」に色違いマテリアルの入ったフォルダを設定して
     「スキャン実行」
  5) 検出されたグループを確認する
     ・不要な色はチェックを外す
     ・★ で初期表示にする色を選ぶ
  6) 「セットアップ実行」
  7) アバターをアップロード

  詳しい手順・画面の説明・困ったときの対処は
  同梱の MANUAL.html をブラウザで開いてご覧ください。
  （ブラウザの印刷機能から PDF として保存できます）


------------------------------------------------------------------------
 5. 何が作られるか / アンインストール
------------------------------------------------------------------------

  セットアップを実行すると、アバター直下に
  「VRCMaterialSwitcherRoot」というオブジェクトが作られ、その中に
  Modular Avatar のコンポーネントが生成されます。

  アバター本体・FX レイヤー・既存のメニューアセットは変更しません。

  このオブジェクトを削除すれば完全に元通りになります。
  ツール内の「全セットアップを削除」からも削除できます。


------------------------------------------------------------------------
 6. 既知の制約
------------------------------------------------------------------------

  ・パラメータは 1 グループにつき Int 1 個（同期時 8 bit）を使います。
    VRChat の同期パラメータ上限は 256 bit です。
    ツール内に現在の消費量が表示されます。

  ・オブジェクト名が重複しているアバターでは、適用先を一意に決められ
    ないためセットアップを中断します。名前を変更してください。

  ・オブジェクト名に「/」を含めることはできません
    （Modular Avatar のパス解決が壊れるため）。

  ・自動での色の見分けは「候補の提示」です。結果は必ず画面で確認して
    ください。意図と違う場合は手動で修正できます。
